25번째 회귀는 8-4에서 신설된 test_gate_error_names_origin — 폴백 경로 계약 위반이 [fallback] 발원지 표식을 달고 울리는지 확인합니다. 7-5 사각지대 → 8-1 게이트 → 8-3 가시화로 이어진 서사가, 이제 "표식이 정확한가"까지 회귀로 잠깁니다.
6-5에서 pytest.main()을 같은 프로세스에서 부르면 모듈 캐시가 오염돼 수정 전 코드로 판정되는 사건이 있었습니다. 그래서 입장권은 항상 __pycache__를 비우고 python -m pytest 서브프로세스로 재판정하며, 신뢰하는 것은 출력 문자열이 아니라 exit 규약입니다.
