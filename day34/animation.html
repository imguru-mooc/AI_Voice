D34 음성 대화 설계 (Voice UX)

받아쓰기 결과를 값으로 바꾸는 한국어 역정규화(ITN), 슬롯 채우기, 암시적 · 명시적 확인, 오류 복구 사다리, 침묵과 맞장구, 상태 머신, 상태 머신 + LLM 혼합을 직접 움직여 보는 수업 자료입니다. 탭 번호 D34-1 ~ D34-9는 노트북 · 워크시트 · 슬라이드의 🎬 번호와 같습니다. 오늘 = 2026년 11월 12일(목)으로 고정합니다.

D34-1오늘 할 것: 꼬일 때를 설계한 예약 대화

단계를 눌러 할 일과 빈칸을 확인하고, 관련 애니메이션으로 이동하세요.

D34-2ITN 놀이터: 들은 말 → 시스템 값

예시를 고르거나 직접 입력하세요. 노트북의 함수와 같은 규칙으로 번호 · 날짜 · 시간 · 진료를 찾고, 어떤 단계를 거쳤는지 보여 줍니다.

    D34-3슬롯 보드: 다섯 칸을 채우는 대화

    "다음 턴"을 누르면 손님 말이 들어오고, 칸이 채워지며 칸마다 확인 방법(암시적 · 명시적)이 붙습니다.

    D34-4확인 전략: 대화 길이 vs 틀린 예약

    예약 1,000건을 흉내 냅니다. 슬롯마다 '잘못 들을 확률'이 있고, 명시적으로 확인한 슬롯은 틀려도 바로 고쳐집니다. 정책과 문턱을 바꿔 보세요(숫자는 설명용 모형).

    D34-5오류 복구 사다리

    손님 반응 버튼을 눌러 보세요. 못 알아들음이 쌓일수록 비서의 말이 바뀌고, 한도에 닿으면 상담원으로 넘깁니다. 값을 알아들으면 횟수가 0으로 돌아갑니다.

    D34-6침묵과 맞장구: 시간 위에서 보기

    손님이 번호를 세 덩어리로 끊어 말합니다. 덩어리 사이 쉼이 '끝점 판단'보다 길면 비서가 턴을 잡습니다. 그때 '네,'(맞장구)로 받으면 손님이 이어 말하고, 쉼이 '자리 비움 시간'을 넘으면 재질문 → 종료로 갑니다.

    D34-7상태 머신 따라가기: 시나리오 10개

    노트북 4-1의 시나리오를 실제 상태 머신으로 돌린 기록입니다(⑧의 LLM 답만 예시 문장). 시나리오를 고르고 한 턴씩 넘기며 상태와 슬롯이 어떻게 바뀌는지 보세요.

    D34-8규칙 + LLM: 말마다 누가 받나

    손님 말을 고르면 llm_node 안에서 상태 머신이 먼저 판단하고, 예약 밖 질문만 LLM으로 보냅니다.
