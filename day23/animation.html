D23 Tool Calling & RAG

LLM이 도구를 '부탁'하고 코드가 실행하는 도구 호출 루프, 도구 설명서(JSON Schema)의 API별 형식, 문서를 조각내 임베딩 · 단어 · 혼합 검색으로 찾는 RAG, 되돌리기 어려운 도구의 확인 질문, 도구 호출과 첫 소리 지연을 직접 움직여 보는 수업 자료입니다. 탭 번호 D23-1 ~ D23-9는 노트북 · 워크시트 · 슬라이드의 🎬 번호와 같습니다. '한빛치과'는 가상 데이터입니다.

D23-1오늘 할 것: 부탁 · 실행 · 찾기 · 확인

단계를 눌러 할 일과 빈칸을 확인하고, 관련 애니메이션으로 이동하세요.

D23-2도구 호출 루프 한 단계씩

질문을 고르고 '다음 ▶'을 누르세요. 파랑 = 사용자, 보라 = LLM, 노랑 = 우리 코드의 실행입니다. LLM은 도구를 실행하지 않고 부탁만 합니다.

D23-3도구 설명서 하나 → 네 가지 형식

도구와 API를 고르면, 한 번 쓴 설명서가 그 API 형식으로 어떻게 바뀌는지와 LLM이 돌려주는 호출 요청의 모양이 나옵니다. 다른 이름은 노란색입니다.

D23-4조각 나누기: 크기와 겹침

조각 크기와 겹침을 바꿔 보세요. 노란 부분이 이웃 조각과 겹친 글자입니다. '토요일은 … 오후 1시까지'가 한 조각 안에 들어가야 질문 '토요일 몇 시까지?'에 잘 맞습니다.

D23-5벡터 검색: 가까운 조각 찾기

질문을 고르면 질문 벡터(★)와 각 조각의 코사인 유사도를 계산해 상위 k개를 고릅니다. 2차원 그림은 설명용으로 줄인 위치입니다.

D23-6의미 · 단어 · 혼합 검색 비교

혼합 점수 = w × 의미 점수 + (1 − w) × 단어 점수 (각각 0 ~ 1로 맞춤). w를 바꿔 질문마다 1위 문서가 정답인지 보세요. 점수는 설명용 예시입니다.

D23-7확인 질문: 예약은 '네' 다음에

비서가 예약을 부탁받은 상태입니다. 사용자의 다음 말을 고르거나 직접 써 보세요. 코드가 '네 / 아니요'를 판정해 실행 · 취소 · 새 요청을 결정합니다.

D23-8도구 호출과 첫 소리

도구를 부를 때마다 LLM 왕복이 하나 더 생깁니다. 단계 수와 시간을 바꾸고 filler('네, 확인해 볼게요')를 켜고 꺼 보세요. 숫자는 설명용입니다.

D23-9이 도구는 확인이 필요할까?

도구 카드를 고르고 '바로 실행 / 확인 후 실행 / 넣지 않음' 중 하나를 고른 뒤 판정을 보세요.
