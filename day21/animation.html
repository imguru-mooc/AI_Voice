D21 Voice Agent 아키텍처

음성 비서의 두 가지 구조(Cascade · Speech-to-Speech), 말 끝 감지(VAD Endpointing), 시간 예산(Latency Budget), Streaming, p50 · p95, 아키텍처 선택을 직접 움직여 보는 수업 자료입니다. 탭 번호 D21-1 ~ D21-9는 노트북 · 워크시트 · 슬라이드의 🎬 번호와 같습니다.

D21-1오늘 할 것: 잇고 · 재고 · 줄이고 · 고른다

단계를 눌러 할 일과 빈칸을 확인하고, 관련 애니메이션으로 이동하세요.

D21-2한 턴이 두 구조를 지나가는 모습

'재생'을 누르면 같은 질문이 Cascade와 S2S를 지나갑니다. Cascade는 단계마다 글(쪽지)이 남고, S2S는 한 모델이 소리를 바로 소리로 바꿉니다. 숫자는 설명용 예입니다.

D21-3Latency Budget 설계기

단계별 시간을 바꿔 합계가 '자연스러움 0.8초' · '고장 난 듯 1.2초' 선을 넘는지 보세요. Streaming을 켜면 LLM 칸이 '답 전체'에서 '첫 문장'으로 바뀝니다.

D21-4v1 순서대로 vs v2 Streaming 타임라인

LLM 속도(초당 토큰), 답의 문장 수와 길이, TTS 속도를 바꿔 '첫 소리'가 언제 나오는지 비교하세요. 빨간 선 = 첫 소리.

D21-5VAD 말 끝 감지: 기다림 vs 잘림

말소리(파란 막대) 사이에 쉼이 있습니다. 침묵 기준을 바꾸면 VAD가 '말 끝'이라고 판단하는 위치(빨간 선)가 바뀝니다. 기준이 쉼보다 짧으면 문장 중간에서 잘립니다. 32 ms 단위로 판단하는 실제 방식을 따랐습니다.

D21-6턴 테이킹: 대화의 틈은 얼마나 짧은가

사람끼리 대화와 음성 비서의 대화를 나란히 재생합니다. 비서의 지연을 바꿔 보며 어느 정도부터 어색한지 귀 대신 눈으로 느껴 보세요.

D21-7p50 · p95: 평균이 숨기는 것

200번의 턴 지연을 만들었습니다. '가끔 느린 응답' 비율과 그때의 지연을 바꾸면 평균 · p50 · p95가 어떻게 움직이는지 보세요. (점 하나 = 턴 하나)

D21-8답 길이 = 지연

LLM은 토큰을 하나씩 만듭니다. 답의 길이(토큰)와 모델 속도를 바꿔 'LLM 시간 = 첫 토큰 + 토큰 수 ÷ 초당 토큰'을 확인하세요. 글자 수는 한국어 기준 대략적인 예입니다.

D21-9아키텍처 선택기

상황을 고르거나 기준별 가중치(0 ~ 3)를 직접 바꾸세요. 구조별 점수(1 ~ 5, 수업 토론용 상대 점수) × 가중치의 합으로 고릅니다. 노트북 빈칸 9의 max(scores, key=scores.get)와 같은 계산입니다.
