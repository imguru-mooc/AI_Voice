D13 PEFT · LoRA Fine-tuning

LoRA 행렬, 도메인 데이터 설계, 프롬프트와 LoRA 비교, 붙일 위치와 파라미터 수, GPU 메모리, 학습률, 어댑터 갈아 끼우기, 양자화를 직접 움직여 보는 수업 자료입니다. 탭 번호 D13-1 ~ D13-9는 노트북 · 워크시트 · 슬라이드의 🎬 번호와 같습니다.

D13-1오늘 할 것: 원래 모델은 두고, 작은 덧붙임으로 용어 가르치기

단계를 눌러 무엇을 하는지 확인하고, 관련 애니메이션으로 이동하세요.

D13-2LoRA 행렬 놀이터

r을 바꾸면 B(세로) · A(가로) 막대의 폭과 학습 파라미터 수가 바뀝니다. "학습 한 번"을 누르면 B가 0에서 조금씩 자라며 ΔW = B·A가 생깁니다.

D13-3도메인 데이터 설계

도메인과 나누는 방식을 바꿔 보세요. 시험 문장이 학습 문장과 겹치면(누수) 점수가 부풀려집니다. 증강 · replay를 켜고 끄면 데이터 수와 위험이 바뀝니다.

D13-4프롬프트 vs LoRA

시험 문장을 고르면 네 방법의 받아쓰기 예시가 나옵니다(설명용 예). 초록 = 용어 맞음, 빨강 = 틀림. 프롬프트 길이(용어 수)를 늘리면 무슨 일이 생기는지 보세요.

D13-5어디에 붙일까: target_modules

LoRA를 붙일 모듈을 고르세요. 모델 크기와 r에 따라 학습 파라미터 수 · 어댑터 파일 크기가 계산됩니다. (Whisper 구조로 계산한 값)

D13-6GPU 메모리: Full · LoRA · 8-bit + LoRA

모델과 batch를 바꿔 세 방식의 메모리를 비교하세요. T4(15 GB) 선을 넘으면 학습할 수 없습니다. (설명용 근사)

D13-7학습률: Full과 LoRA는 다르다

방식을 고르고 학습률을 바꿔 보세요. 같은 1e-3이라도 Full에는 너무 크고 LoRA에는 알맞습니다. (설명용 모형)

D13-8어댑터 갈아 끼우기

원래 모델에 끼울 어댑터와 받아쓸 문장 분야를 고르세요. 맞는 어댑터를 끼우면 용어를 잘 맞히고, 다른 분야 어댑터는 도움이 안 됩니다. "병합"을 누르면 어댑터를 W에 합칩니다. (설명용 예)

D13-9양자화와 가중치 메모리

비트 수와 모델을 바꾸면 가중치 메모리와 숫자의 정밀도(표현할 수 있는 칸 수)가 바뀝니다.
