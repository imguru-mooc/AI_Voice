D11 한국어 음성 데이터셋

한국어 음성 데이터셋의 지도, Hugging Face 스트리밍, KsponSpeech 전사 규칙과 PCM, AIHub 형식에서 목록표 만들기, 품질 필터, 화자 단위 분할, Whisper 학습 입력 변환을 직접 움직여 보는 수업 자료입니다. 탭 번호 D11-1 ~ D11-9는 노트북 · 워크시트 · 슬라이드의 🎬 번호와 같습니다.

D11-1오늘 할 것: 우리 데이터로 고쳐 쓰기 위한 '깨끗한 데이터' 만들기

3주차 첫날입니다. 단계를 눌러 무엇을 하는지 확인하고, 관련 애니메이션으로 이동하세요.

D11-2한국어 음성 데이터셋 지도

원 하나가 데이터셋 하나입니다(크기 = 규모, 위치는 설명용). 원을 누르면 말투 · 규모 · 라이선스 · 받는 법이 나옵니다. 아래에서 만들 서비스를 고르면 어울리는 데이터셋을 표시합니다.

D11-3통째로 받기 vs 스트리밍

"시작"을 누르면 두 방식이 동시에 출발합니다. 통째로 받기는 전체를 받은 뒤에야 첫 샘플을 보고, 스트리밍은 바로 보기 시작합니다. 볼 샘플 수를 바꿔 보세요. (설명용 속도)

D11-4KsponSpeech 전사 정제기

KsponSpeech 형식 문장을 입력하거나 예시를 고르세요. 노트북의 clean_kspon()과 같은 순서(① 이중 전사 → ② 잡음 태그 → ③ + * / → ④ 공백)로 정리합니다.

D11-5PCM 바이트를 숫자로 읽기

KsponSpeech .pcm은 머리말 없이 소리 숫자만 있습니다. 읽는 방법(자료형 · 바이트 순서 · 머리말 건너뛰기)을 바꿔 보세요. 맞게 읽으면 매끈한 파형, 틀리면 잡음이 됩니다.

D11-6폴더 → 목록표 한 줄

왼쪽 파일을 누르면 짝이 되는 파일을 찾고, 라벨에서 전사 · 화자를 꺼내 목록표 한 줄을 만듭니다. "모두 처리"로 전체 목록표를 만드세요.
